## Música de fundo
O YouTube bloqueou o download automático do remix de K-PSZH.

**Como colocar o áudio (1 minuto):**
1. Abra: https://www.youtube.com/watch?v=Ej3cm9LecgA
2. Baixe o áudio com qualquer conversor (ou yt-dlp / 4K Video Downloader / etc.)
3. Renomeie o arquivo para: `lets-kill-each-other-kpszh.mp3`
4. Coloque o MP3 na mesma pasta do `index.html`
5. Abra o HTML e clique em **TOCAR**
